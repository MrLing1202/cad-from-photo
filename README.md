# 图注成线

从平面图照片提取尺寸标注，用于核验已有 CAD 图，或依据标注轴网生成可编辑 DXF。

## 背景

平面图照片经手机拍摄后带有透视变换，打印件另有比例形变。墙线在图像上的量测值不能等同于设计尺寸，像素级比对在常规精度下不可用。

图上标注由设计者填写，是唯一可信的尺寸来源。本工具以标注为真值重建轴网，再与 CAD 数据双向对账。

某次实际核验中，62 个去重标注与 145 条 DWG 直线比对。初始以墙线像素坐标为依据，未能闭合。改以标注为真值后闭合，其中 6 个标注由相减关系解释，1 个确认为缺失。

由此定下三条：墙线先做双线合并还原轴线，再合计轴距；轴距由轴线坐标两两求差，不用线段端点距离；标注必须带方向，缺方向的命中一律标为可疑。

| 输入 | 输出 |
|:---|:---|
| 照片与已有 DWG / DXF | 逐条标注的核验结论 |
| 仅有照片 | 可编辑 DXF |

## 环境

```bash
pip install ezdxf pillow pywin32
```

`pywin32` 仅用于 DWG 转换，依赖本机 AutoCAD。DXF 输入无需此项。

## 流程

**一、标注提取**

```bash
python scripts/read_annotations.py --image 平面图.jpg --outdir temp/ann --grid 3x3
```

按 3x3 切分识别，低置信度数值以 `--points` 定点放大复核。输出切片与标注坐标。

**二、实体抽取**

```bash
python scripts/dump_entities.py --file 原图.dwg --out temp/entities.json
```

DWG 经 AutoCAD 转换后解析，DXF 直接读取。输出线段端点与长度，可按图层过滤。

**三、对账**

```bash
python scripts/axis_check.py --entities temp/entities.json --ann "10640:H,8500:V" --outdir temp
```

标注集与实体集双向比对，输出 `report.txt` 与 `axis.json`。

**四、成线**

```bash
python scripts/build_dxf.py --spec temp/spec.json --out temp/plan.dxf
```

按轴网生成双线墙体、洞口与尺寸链。生成物须经同一标注集回检，A 向命中率应达 100%。

## 两个方向

对账做两次，方向相反。

A 向，标注到图。取一条标注的数值，到图上找等长的距离。找得到，这根墙画了。找不到，报缺。

B 向，图到标注。取图上每根线的长度，问它能不能由标注算出来。单值吻合、两标注之和、两标注之差、扣墙厚后吻合，都算有解释。一条都对不上，这段墙多半是凭空画的。

A 向查漏画，B 向查多画。两次都过，才算闭合。

## 参数

| 参数 | 脚本 | 含义 |
|:---|:---|:---|
| `--image` | 标注提取 | 平面图照片 |
| `--outdir` | 标注提取、对账 | 输出目录 |
| `--grid` | 标注提取 | 切分网格，缺省 `3x3` |
| `--scale` | 标注提取 | 分区放大倍数，缺省 2 |
| `--points` | 标注提取 | 定点复核，格式 `值:x:y;...` |
| `--file` | 实体抽取 | DWG 或 DXF |
| `--out` | 实体抽取、成线 | 输出文件 |
| `--layers` | 实体抽取 | 只取这些图层，逗号分隔，不填取全部 |
| `--entities` | 对账 | 实体抽取产出的 JSON |
| `--ann` | 对账 | 轴距类标注，两道轴线之间的距离，格式 `数值:H` 或 `数值:V` |
| `--ann-line` | 对账 | 单线类标注，图上某根线自身的长度，须同轴段内命中 |
| `--ann-file` | 对账 | 从文件读取标注值 |
| `--from-spec` | 对账 | 由轴网自动生成标注集，用于自检 |
| `--tol` | 对账 | 判定容差，缺省 25mm |
| `--dim-line` | 对账 | 报告中详列不小于此值的标注，缺省 2000mm |
| `--no-merge` | 对账 | 关闭墙皮双线合并 |
| `--spec` | 成线 | 轴网数据 |

各脚本均可加 `--help` 查看。

## 数据契约

```json
{
  "walls_x": [0, 1600, 4400, 7200, 10640],
  "walls_y": [0, 2800, 4950, 8500],
  "thickness": 200,
  "wall_thickness": {"x": [240, 200, 200, 200, 240], "y": [240, 200, 200, 240]},
  "openings": [{"axis": "x", "at": 0, "from": 600, "to": 1500, "type": "door"}],
  "dim": {"enabled": true, "offset": 1200}
}
```

| 字段 | 含义 |
|:---|:---|
| `walls_x` `walls_y` | 轴线绝对坐标，单位 mm。轴距由脚本按相邻差值计算，不由人工填写 |
| `thickness` | 全局墙厚，缺省 200 |
| `wall_thickness` | 按轴向细分墙厚。可给单值，也可按轴线逐道给数组 |
| `openings` | 洞口，`type` 取 `door` 或 `window` |
| `dim` | 尺寸链，`offset` 为标注线距外墙的距离 |

`wall_thickness` 的数组长度须等于该向轴线数。长度不符时退回 `thickness`，不报错，图会安静地错。

墙厚只作用于成图。对账不读取该字段，口径差由 `axis_check` 内置的标准墙厚表比对得出。墙厚未知时应先实测再出图，不得沿用缺省值。

标注方向由 `--ann` 的 `H` / `V` 后缀给出，不属于 spec。缺省方向将产生跨轴误命中，同图内等值巧合多由此而来。

## 判定

| 差值 | 结论 | 处理 |
|:---|:---|:---|
| ≤ 10mm | 对 | 忽略 |
| 10 至 50mm | 存疑 | 多为取整差异，人工复核 |
| 接近墙厚量级 | 口径差 | 净空与含墙厚之差，不作判定 |
| 跨轴等值 | 跨轴 | 回到坐标核实 |
| 其余 | 缺或画错 | 需修图 |

判定顺序依「缺」、「存疑」、「口径差」递次处理。跨轴命中须回到坐标核实，等值不构成证据。

## 限制

- 透视畸变显著时墙线角度失真，双线合并失效，须先人工校正
- 同一轴线并存多种墙厚时，轴线定位存在偏移，应核对 `axis.json` 中的 key 值
- 标注受遮挡或断裂时，以标注集缺口如实反映，不得以对称性推定
- 图幅仅覆盖局部时，判缺前须确认该墙不在图幅范围内
